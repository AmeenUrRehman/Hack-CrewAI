# Hack-CrewAI 🚀🤖

Hack-CrewAI is a collection of autonomous multi-agent systems built using [CrewAI](https://github.com/joaomdmoura/crewAI). Each project demonstrates how AI agents can collaborate to perform complex real-world tasks with minimal human intervention.

## 🔧 Projects Included

### 1. Customer Support Automation
An AI-powered support agent system that answers user queries, generates responses, and routes issues based on context. Ideal for automating help desks or onboarding systems.

### 2. Research Report Writer
Automated research assistant that takes a user-defined topic and generates a structured research report using intelligent agent collaboration for sourcing, summarization, and synthesis.

### 3. Trip Planner
A smart trip planning assistant that tailors itineraries based on user preferences, destination data, and real-time factors like dates, interests, and origin city.

## 🧠 Built With

- [CrewAI](https://github.com/joaomdmoura/crewAI) — Autonomous multi-agent framework  
- [LangChain](https://www.langchain.com/) — Tooling for agent workflows  
- [OpenAI API](https://platform.openai.com) — Large language models  
- Python libraries: `dotenv`, `pandas`, `reportlab`, etc.
